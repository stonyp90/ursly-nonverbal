# Ursly — Analyse non verbale

La page concept de **nonverbal.ursly.io** : la vue et l'ouïe d'Ursly appliquées
aux signaux de tension pendant qu'une personne parle.

- `index.html` — la page (hero vidéo 15 s : 5 scènes × 3 s avec overlay
  d'analyse sur le visage ; le concept ; temps réel vs après coup ; les
  contextes ; les autres sens ; les limites honnêtes).
- `assets/hero-nonverbal-15s.mp4` — la vidéo d'arrière-plan composée
  (scènes générées dans `assets/raw/`, boîtes et panneaux dessinés au
  compositing, coordonnées relues sur les frames).
- `assets/splash-ursly.mp4` — la splash animation Ursly du produit.
- `assets/poster.jpg` — l'affiche du hero.

Position du produit (inchangée) : un **indice de tension + confiance**,
jamais un verdict de mensonge. Le moteur d'analyse vit dans le dépôt
`truthlens` (à renommer) ; cette page est la devanture Ursly du produit.

Marque : Ursly compte **cinq sens** — vue, ouïe, odorat, goût, toucher.
Le mouvement est mesuré comme un signal ; ce n'est pas un sens.
